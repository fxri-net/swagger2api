# 项目协作规范索引

> 本文件为规范载体唯一入口与唯一权威；规范全貌见下方索引，条文见各分册。
> 读面纪律：`history.md` / `retired.md` 属归档面，仅在审计 / 恢复时读，不在常规读面。

## 一、端清单

> 端名与任务 frontmatter 的 `scope` 取值共用同一套词表；保留字 `index` / `common` 不得作端名。本项目单端，规范全归 `common`。

| 端名 | 说明 |
| --- | --- |
| swagger2api | 本项目唯一交付端（CLI 包本体 + 文档站） |

## 三、用法说明

- **载体形态**：本项目采用「溯源索引式与条文式混用」（既有条文属「溯源索引式」，条文在外部规则层，本载体只索引；新增条文全文落 `common.md`，属「条文式」）。
- **本项目约定**：不建端分册与分类标签分册；任务 `scope` 中 `docs` / `依赖治理` / `工程规范` / `全局规则` 等取值为分类标签而非端，读取时静默跳过。
- **读写与维护**：读面与读写判定、写入归属、语义修订与退休流程一律见 `skills/fxri-plan-to-task/references/conventions-spec.md`，本载体不另述。

# 优化 CI 流程对齐 toolkit 范式

## 背景

参考同工作区的 `@fxri/toolkit` 仓库 CI 范式，疏理本项目 CI 的结构性问题：

- **两端 CI 分支口径写死 `master`，实际默认分支为 `main`**（`git ls-remote --heads` 实测 origin 与 github 均只有 `main`），导致文档站部署流水线**从未被触发**；`docs/.vitepress/config.mts` 的 `editLink` 同样写死 `/edit/master/`，编辑链接必然 404
- **只有部署、没有门禁**：无 typecheck / lint / build 校验，`package.json` 无 `verify` 聚合命令，步骤清单散落在各 CI 配置里
- 版本口径三处漂移：GitLab `node:20`、GitHub `node-version: 20`，而 `.node-version` 为 `20.20.2`；GitLab 另以 `corepack prepare pnpm@10.34.4 --activate` 硬编 pnpm 版本
- GitLab 配置无 `stages`，`rules` 在 `workflow` 与 job 各写一份
- 根 `CHANGELOG.md` 变更会改变文档站更新日志页，但两个 workflow 的 `paths` 均未包含它
- `docs/changelog.md` 为生成物，缺少「是否与 `CHANGELOG.md` 同步」的拦截

本机实测结论（决定门禁步骤可行性）：

- `tsc --noEmit` exit 0；`pnpm build` exit 0（仅一条 `import.meta` 在 CJS 下的 esbuild warning）
- `eslint . --no-cache` exit 0 属**假通过**——默认只匹配 `.js`，本仓库无 `.js`，实际检查 0 个文件；须显式 glob。`--ext .ts,.cjs,.js` 在 PowerShell 下逗号被拆参报错，不可用
- `node dist/cli.js --help` **不是帮助开关**：`src/cli.ts` 无参数解析，直接进交互式选配置，CI 中会挂住；CLI 冒烟改为 `import('./dist/index.js')` 断言 `generateApi`（`src/index.ts:237` 导出）为函数

# 开放更新日志页目录

延续 新增文档站（见 archive/202609/20260906.md）

## 背景

文档站「更新日志」页（docs/changelog.md）右侧无「本页目录」，与其余 5 页不一致：该页是唯一带 frontmatter 的内容页，且 frontmatter 中写死了 `outline: false`。

该 frontmatter 由生成脚本 [scripts/sync-changelog-doc.mjs](file:///d:/Work/Dev-Space/fxri/0001.base/swagger2api/scripts/sync-changelog-doc.mjs#L13-L19) 写入，docs/changelog.md 是纯生成物（页内引言已标明「请勿手改」），故只能改脚本模板再重新同步，手改页面会被下次 `pnpm sync:changelog-doc` 覆盖。

档位定为 `[2, 2]`：本页有 25 个版本块（h2）且每块下通常还有 1~2 个分组标题（h3），沿用全局 `[2, 3]` 目录约 60 条过长，只列版本号更便于按版本跳转。

## 实施步骤

1. 改 scripts/sync-changelog-doc.mjs 生成模板：frontmatter 由 `outline: false` 改为 `outline: [2, 2]`
2. 执行 `pnpm sync:changelog-doc` 重新生成 docs/changelog.md（幂等，仅该行有净改动）

## 附带修正

同步时发现剥标题正则不幂等：根 CHANGELOG.md 在 Windows 检出为 CRLF，旧写法 `[^\n]*\n+` 只吃 `\n`，残留的 `\r` 会在引言与首个版本块之间多生成一个空行（同文件在 Linux 检出为 LF，不会出现该空行，属平台相关产物漂移）。本次改为 `^#\s+[^\r\n]*(?:\r?\n)+`，LF 输入行为不变，CRLF 输入不再残留空行。此修正使本次改动前后 docs/changelog.md 的差异收敛为 frontmatter 一行。

## 影响范围

- scripts/sync-changelog-doc.mjs、docs/changelog.md（生成物）
- 不影响 CLI 运行时代码与包产物：scripts 不在 package.json#files 白名单
- 无需改 CI 配置：两处流水线触发路径已含 `docs/**` 与 `scripts/sync-changelog-doc.mjs`

## 验证与回滚

- 验收：`pnpm docs:build`（与 deploy-docs.yml / .gitlab-ci.yml 同源命令）
- 核对 docs/changelog.md 除 frontmatter 外正文与根 CHANGELOG.md 一致
- 回滚：sync 脚本改回 `outline: false` 后重新执行 `pnpm sync:changelog-doc`

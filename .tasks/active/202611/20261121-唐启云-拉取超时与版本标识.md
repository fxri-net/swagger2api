# 拉取超时与版本标识

> 计划位置：第 5 个（共 6 个）；前置：无；后继：无

## 背景

- 拉取 Swagger 文档没有显式超时；源站卡住时 AI 代理与 CI 会长时间等待，失败信息也不友好。
- 缺少 `--version`：AI 与 CI 无法在日志里记录实际使用的工具版本，排查与复现困难（产物清单刻意不带版本，但运行期需要标识）。

## 实施方案

1. 新增 `input.timeout`（单位毫秒，默认 30000）与 `--timeout <ms>` 覆盖；地址不可达、连接超时、响应超时统一转换为可读错误，提示「可重试或改用本地快照」，退出码 1。
2. 新增 `swagger2api --version`，输出版本号（纯文本一行）；诊断命令 JSON 的 `toolVersion` 复用同一来源。
3. 单测覆盖配置解析与非法值回落告警；夹具用本地 HTTP 服务模拟慢响应，断言超时退出与提示。
4. 文档与技能补两个入口；变更集标 patch。

## 影响范围

- 文档拉取与配置解析、CLI 版本输出、单测与夹具、`docs/cli.md` / `docs/config.md`、技能 `references/cli.md`、变更集。

## 验证方式

- `pnpm test` 与 `pnpm build:debug` 后 `pnpm verify` 通过。
- 慢响应夹具在默认超时下退出码 1 且提示可重试；`--timeout` 覆盖生效。

## 回滚方案

移除超时与版本输出的改动、还原文档与变更集；默认行为回到无显式超时。

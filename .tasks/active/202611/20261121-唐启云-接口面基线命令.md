# 接口面基线命令

> 计划位置：第 3 个（共 3 个）；前置：20261121-唐启云-内置后处理与产物校验；后继：无

## 背景

- 业务仓为迁移比对，各自维护 `scripts/api-surface.mjs`，从生成文件提取 `@request` / `@name` / 导出类型；这属于工具的迁移辅助能力。
- 目标：工具内置接口面摘要与比对，业务仓不保留脚本，只在需要时生成 / 比较基线文件。

## 实施方案

1. **命令**：`swagger2api surface --config <配置> [--target <id>] [--out <文件>] [--compare <基线>] [--requests-only] [--json]`。
2. **提取**：从 `.ts` / `.d.ts` / `.js` 提取 `@request`、`@name` 与导出类型，排序去重；多目标按目标 `id` 分组；提取结果带 `formatVersion` 锚点。
3. **基线**：`--out` 写到指定文件（建议 `.swagger2api/surface.json`，默认不提交）；`--compare` 输出增删项并以非 0 退出；`--requests-only` 只锁接口集合，供跨工具版本迁移使用；多目标比对时目标集合变化（新增 / 缺失目标）同样报错。
4. **测试**：TS / JS、单 / 多目标、基线一致与增删、缺失基线、JSON 结构。
5. **文档**：`docs/cli.md`、`skills/fxri-swagger2api/references/migration.md`。
6. **变更集与版本**：patch，目标版本 **1.3.2**；条目按「修复」书写；技能 references 变更时递增 `fxri-swagger2api` 技能版本；不单独发版，与其余工具任务一起发 1.3.2。

## 影响范围

- 新增接口面提取与命令实现、测试
- `docs/cli.md`、技能 references、`.changeset/`

## 验证方式

- 同一产物两次提取结果一致；基线一致时退出 0，增删时指出具体条目。
- 多目标汇总正确；`--requests-only` 忽略类型命名差异。
- `pnpm verify` 全量通过。

## 回滚

移除 `surface` 命令与提取实现，不影响生成链路。

# 治理 GitHub 依赖漏洞告警

## 目标

GitHub Dependabot 报告仓库默认分支 49 个依赖漏洞告警（26 high / 22 moderate / 1 low），需升级依赖修复。判定依据：https://github.com/fxri-net/swagger2api/security/dependabot（推送 v1.2.5 后 GitHub 反馈，时间证据级 1）。

## 建议步骤

1. 拉取告警清单，确认受影响包均属 devDependencies（不影响已发布产物运行时）
2. 优先处理 high 级：升级对应 devDependencies 至修复版本
3. `pnpm install` + `pnpm build` 回归
4. 创建变更集（若涉及产物行为则 patch/minor，纯 devDeps 可不出变更集）按项目发版流程发布
5. 复验 Dependabot 告警清零

## 影响范围

- 仅 devDependencies / pnpm-lock.yaml，不触及 src/ 运行时代码

## 验证与回滚

- 验证：Dependabot 告警清零、build 通过
- 回滚：git 回退依赖升级提交即可
